## 📖 게임 소개

> *"진입은 은밀하게, 탈출은 화려하게. 잠입 액션과 무쌍을 합친 FPS 게임"*

**ProjectH**는 테러리스트가 점거한 건물에 침투해 인질을 구출하는 1인칭 잠입 액션 슈터 게임입니다.

플레이어는 대테러 요원으로서 1~3층을 은밀히 잠입해 서버실 데이터를 확보하고, 12층에 감금된 수석 연구원을 구출한 뒤 옥상 헬기로 탈출해야 합니다.

단 한 발의 총성도 연쇄 경보의 신호탄이 될 수 있습니다. **암살할지, 조용히 지나갈지** — 모든 선택은 플레이어의 몫입니다.

### 게임 장르 참고작

| 참고작 | 벤치마킹 요소 |
|--------|--------------|
| **히트맨 시리즈** | 정교한 잠입, 적 패턴 분석, 환경 활용 암살 |
| **헬다이버즈 2** | 목표 달성 후 쏟아지는 적을 상대하는 박진감 넘치는 총격전 |
| **메탈 기어 솔리드** | 적 시야각 및 상태 머신 기반 전술적 긴장감 |
| **데우스 엑스** | 환풍구·서버실·천장 등 복합적인 잠입 경로 |
| **존 윅 시리즈** | 다양한 살상 연출과 타격감 |

## 🗺 게임 흐름

| 단계 | 장소 | 목표 | 특징 |
|------|------|------|------|
| **1단계** | 1F 로비/물류창고 | 건물 침투 | 잠입 시작, 초기 무장 (소음 권총) |
| **2단계** | 2F 휴게실/사무공간 | 상층 이동 | CCTV·순찰병 밀집 고난도 잠입 구간 |
| **3단계** | 3F 서버실 | 연구 데이터 확보 | 장르 전환 기점, 엘리베이터로 12층 이동 |
| **4단계** | 12F 보스 구역 | 보스 처치 + 인질 구출 | 돌격소총 획득, 3페이즈 보스전 |
| **5단계** | 13F | 탈출 돌파 | 증원 적 물량 대응 |
| **6단계** | 옥상 | 헬기 탑승 탈출 | 타임 리밋 5분, 게임 클리어 |

> 엘리베이터 진입 시 헬기가 공격받기 시작 → **5분 타임 리밋** 시작

- **체크포인트 저장** — 층별 계단마다 세이브 포인트, 위치·무기·열쇠·처치 수 저장

### 🤖 적 AI 시스템

경계 레벨 4단계로 구성되며, 시각과 청각을 복합적으로 활용합니다.

| 단계 | 상태 | 설명 |
|------|------|------|
| **Idle** | 순찰 | 설정된 경로 순찰 또는 제자리 경계 |
| **Suspicious** | 의심 | 소리는 들었지만 모습은 못 본 상태 |
| **Combat** | 전투 | 플레이어 발견, 사격 개시 |
| **Search** | 추격 | 플레이어를 놓친 후 마지막 위치로 이동 |

**상태별 AI 수치**

| 상태 | 시야각 | 탐지 거리 | 청각 범위 | 이동속도 |
|------|--------|----------|----------|---------|
| Idle | 100° | 10m | 5m | 400 cm/s |
| Suspicious | 100° | 15m | 8m | 600 cm/s |
| Combat | 100° | 20m | 10m | 800 cm/s |
| Search | 100° | 20m | 10m | 800 cm/s |

**적 스탯**

| 등급 | 체력 | 데미지 | 명중률 |
|------|------|--------|--------|
| 일반 (Normal) | 100 | 15 | 30% |
| 정예 (Elite) | 150 | 20 | 30% |

- **Alert Manager** — 적 발각 시 경보 범위(20m) 내 모든 적 Combat 전환
- **CCTV** — 시야각 120°, 탐지 거리 20m. 파괴 가능하며 감지 시 주변 적에게 경보 전달
- **동적 스폰** — 발각 시 주변 스폰 포인트에서 적 2~3명 추가 스폰

### 👹 보스 전투 (12F)

| 페이즈 | 체력 구간 | 패턴 |
|--------|----------|------|
| Phase 1 | 100% ~ 60% | 5발 연사 (0.3초 간격) |
| Phase 2 | 60% ~ 30% | 연사 + 수류탄 투척 + 일반 적 2명 증원 |
| Phase 3 | 30% ~ 0% | 전체 패턴 + 1.5초 레이저 경고 → 고데미지 정밀 사격 (80 dmg) |

> 보스 기본 스탯: 체력 500 / 공격력 35 / FOV 360° (전방위 탐지)

---

### 🧑‍🤝‍🧑 인질 시스템

- **F키** — 인질 상태 전환 (대기 ↔ 따라오기)
- **이동 속도** — 플레이어와 동일하게 동기화
- **아군 오사** — 플레이어 공격 데미지 최대 20으로 제한
- **길찾기 보정** — 500 unit 이상 거리 벌어지면 Stay 상태로 강제 전환

| 상태 | 설명 |
|------|------|
| Stay | 제자리 대기 (불안한 대기 모션) |
| Following | 플레이어를 따라 이동 |
| Dead | 사망 → 미션 실패 트리거 |

---

### 💀 리스폰 시스템

1. 사망 → 입력 차단 + 사망 애니메이션
2. 화면 페이드 아웃
3. 최근 체크포인트로 위치 이동
4. 체력 100 복구, 자동 재장전
5. 페이드 인 + 입력 재개

## 🗂 프로젝트 구조

```
Source/Sparta_H/
├── Characters/     # 플레이어 캐릭터, 체력·스태미너·소음·가시성 컴포넌트
├── Enemy/          # 일반 적, 보스, CCTV, 경계 시스템
├── Weapon/         # 무기 베이스, 투척물, 탄약 컴포넌트
├── AI/             # AI 컨트롤러
├── Hostage/        # 인질 캐릭터 및 AI
├── Systems/        # 전투 관리, 데미지, 미션, 세이브, 히트 감지
├── Level/          # 문, 엘리베이터, 로프, BGM 트리거
├── Spawn/          # 스폰 볼륨, 리스폰 트리거
├── UI/             # HUD, 크로스헤어, 무기 슬롯, 미션·타이머·실패 위젯
└── Framework/      # 게임 모드, 플레이어 컨트롤러
```
